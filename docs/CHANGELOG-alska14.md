## 예외 요청 승인이 실제로 적용되도록 (PR 17 외)

- 승인된 요청이 허용 시간 동안 해당 항목 종류를 그대로 통과시킵니다 (브라우저 번호 + 항목 종류 + 사이트 기준). 1회 승인은 실제로 내보낸 첫 전송에서 소진되고, 감사 기록에 `exception_id`가 남습니다. 다른 항목 때문에 어차피 막힌 전송은 1회 승인을 쓰지 않습니다.
- 확장: 사용하면 "사용 완료" 또는 남은 시간 알림, 옛 "1회만 허용돼요" 줄 삭제, 팝업 목록에 "사용 완료".
- 확장: 말풍선은 항상 아래 채팅 입력창 전체의 오른쪽 위에 붙습니다. ChatGPT의 메일 카드 안에서 글을 써도 검사 말풍선은 아래에 뜨고, 카드 안 Enter는 전송으로 가로채지 않습니다.
