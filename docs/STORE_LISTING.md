# Chrome 웹 스토어에 올리기

확장을 스토어에 올리면 사용자 Chrome이 새 버전을 알아서 받습니다. 지금처럼 폴더를 직접 로드하는 방식은 자동 업데이트가 없습니다.
계정 만들기, 결제, 제출은 직접 해야 하고, 아래는 제출 화면에 넣을 내용입니다.

## 순서

1. 설치용 압축 파일 만들기: `python scripts/pack_extension.py` → `dist/llm-gateway-guard-<버전>.zip`. 검사에 걸리면 이유를 알려 주고 만들지 않습니다.
2. [Chrome 웹 스토어 개발자 대시보드](https://chrome.google.com/webstore/devconsole)에서 개발자로 등록합니다 (구글 계정, 1회 등록비가 있습니다. 금액은 화면에서 확인하세요).
3. 새 항목 → 위 zip 업로드 → 아래 내용을 칸마다 붙여 넣기 → **공개 범위를 "비공개(링크가 있는 사람만)"** 로 두고 제출.
4. 심사는 보통 며칠 걸립니다. 통과하면 받은 링크를 직원에게 나눠 줍니다.

**새 버전을 올릴 때**: `extension/manifest.json`의 `version`을 올리고(같거나 낮으면 업로드가 거절됩니다), 다시 `pack_extension.py`를 돌려 새 zip을 대시보드에 올립니다. 심사를 통과하면 사용자의 Chrome이 몇 시간 안에 자동으로 받습니다.

## 제출 전에 채울 것 (비어 있으면 반려됩니다)

- [ ] `frontend/public/privacy.html` 맨 아래 **문의 연락처**를 실제 이름과 이메일로 바꾸기 (지금은 노란색 안내 문구)
- [ ] 개인정보 처리 방침 주소로 쓸 서버를 정하기: 배포한 게이트웨이의 `https://<주소>/privacy.html` (재배포해야 열립니다)
- [ ] 심사자용 접속 키를 새로 만들고(`python -m app.keys reviewer`) Railway의 `GATEWAY_API_KEYS`에 추가하기. **저장소나 이 문서에는 적지 말고 제출 화면의 "테스트 지침"에만 넣으세요.** 심사가 끝나면 지웁니다
- [ ] 스크린샷 1장 이상 (1280x800 또는 640x400): `extension/dev/fake-chat.html`(검토 창)과 팝업 화면을 캡처
- [ ] 작은 홍보 이미지 440x280 (필수), 아이콘 128px은 이미 `extension/icons/`에 있음

## 칸별 내용

**이름**: LLM Gateway Guard

**요약 (132자 이내)**: ChatGPT·Claude에 글을 보내기 전에 회사 게이트웨이로 민감정보를 가리고, 답변에서는 원래 값으로 되돌려 보여 줍니다.

**카테고리**: 업무 도구 (Productivity)

**언어**: 한국어

**자세한 설명**

> 회사가 ChatGPT나 Claude를 쓰게 하면서도 고객 정보, 영업기밀, 키 같은 것이 밖으로 나가지 않게 하는 확장입니다.
>
> • 보내기 직전에 입력한 글을 회사 게이트웨이 서버로 보내 민감정보(이름, 연락처, 주민등록번호, 업종별 영업기밀, API 키 등)를 찾습니다.
> • 가려도 되는 것은 [사람_1] 같은 이름표로 바꿔서 보내고, 바꾸기 전에 검토 창에서 확인할 수 있습니다.
> • 보내면 안 되는 것(키, 비밀번호 등)은 전송을 막습니다.
> • 답변에 이름표가 있으면 화면에서만 원래 값으로 되돌려 보여 줍니다.
> • 원래 값은 서버에 저장되지 않고, 서버에는 "언제, 어떤 종류가 몇 개"만 남습니다.
>
> 사용하려면 회사가 운영하는 게이트웨이 서버의 주소(와 접속 키)가 필요합니다. 확장 팝업의 "연결 설정"에 넣으세요. 서버가 없으면 동작하지 않습니다.
> 이 확장은 직원이 끌 수 있는 보조 장치이며, 회사 전체에 강제하려면 별도의 정책 설치가 필요합니다.

**단일 목적 설명 (Single purpose)**: 사용자가 ChatGPT·Claude에 보내는 글에서 민감정보를 찾아 가리고, 답변에서 되돌려 보여 주는 것.

## 권한 설명 (제출 화면의 "권한 사유")

| 권한 | 사유 |
|---|---|
| `storage` | 게이트웨이 주소, 접속 키, 켜기·끄기, 선택한 업종, 오늘 검사 횟수를 이 브라우저에 저장합니다. |
| 호스트: `chatgpt.com`, `chat.openai.com`, `claude.ai` (콘텐츠 스크립트) | 입력창의 글을 보내기 직전에 검사하고 답변의 이름표를 되돌려 보여 주기 위해서입니다. 이 사이트들에서만 동작합니다. |
| 호스트: `http://localhost:8000` | 내 PC에서 게이트웨이를 켜고 시험할 때의 기본 주소입니다. |
| 선택 호스트: `https://*/*`, `http://*/*` | 회사마다 게이트웨이 주소가 달라, 사용자가 팝업에 넣은 그 주소 하나에 대해서만 Chrome이 허용을 묻습니다. 내 PC 밖의 서버는 `https`만 받습니다. 다른 사이트로는 요청을 보내지 않습니다. |

원격 코드 사용: **아니요** (모든 코드는 패키지 안에 있고 `eval`과 외부 스크립트를 쓰지 않습니다. `pack_extension.py`가 검사합니다.)

## 데이터 사용 공개 (대시보드 "개인정보 보호" 탭)

수집하는 항목으로 체크할 것: **웹사이트 콘텐츠**(입력한 글), **인증 정보**(사용자가 넣은 접속 키, 이 기기에만 저장).
공개 내용: 모두 확장 기능 제공을 위해서만 쓰고, 사용자가 설정한 회사 게이트웨이로만 보내며, 판매·광고·무관한 목적·신용 평가에 쓰지 않는다고 세 가지 인증 항목에 모두 체크합니다.
개인정보 처리 방침 URL: `https://<배포한 주소>/privacy.html`

## 심사자용 테스트 지침 (제출 화면에 붙여 넣기)

> 이 확장은 회사의 게이트웨이 서버가 있어야 동작합니다. 시험용 서버를 준비했습니다.
> 1. 확장 아이콘 → "연결 설정"에서 게이트웨이 주소에 `<배포한 주소>`, 접속 키에 `<심사자용 키>`를 넣고 저장합니다 (Chrome이 주소 접근 권한을 물으면 허용).
> 2. 상태가 "게이트웨이 연결됨"인지 확인합니다.
> 3. chatgpt.com 또는 claude.ai(로그인 필요)에서 `고객 홍길동 메일 kim@corp.co.kr 로 보내줘`를 입력하고 보내면, 바꿀 항목을 보여 주는 검토 창이 뜹니다. 확인하면 `[사람_1]`, `[이메일_1]`로 바뀐 글이 전송됩니다.
> 4. `sk-abcdefghijklmnopqrstuvwxyz123456`처럼 키가 들어간 글은 전송이 막힙니다.
> 모든 값은 가짜입니다. 시험용 서버의 모델은 가짜라서 답이 보낸 글을 되돌려 줍니다.

## 알아둘 점

- 스토어 심사는 "파일 검사 데모"와 "회사 계정 가입·로그인(데모)" 화면 같은 **실제로는 동작하지 않는 기능**을 문제 삼을 수 있습니다. 둘 다 기본으로 꺼져 있거나 데모라고 표시되어 있지만, 걸리면 해당 화면을 빼고 다시 제출하는 것이 안전합니다.
- 팀원이 확장 코드를 고치면 `pack_extension.py`와 새 버전 업로드가 다시 필요합니다. 서버 쪽 변경(규칙, 정책, 템플릿)은 스토어와 무관하게 바로 적용됩니다.
- 비공개로 올려도 링크를 가진 사람은 누구나 설치할 수 있습니다. 회사 전체에 강제 설치하려면 Chrome 기업 정책(`ExtensionInstallForcelist`)에 이 확장의 ID를 넣으세요.
