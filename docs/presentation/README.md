## 발표 시점의 구현 상태

발표문은 실제로 되는 것만 말하도록 썼습니다. 당시 기준으로 정리하면 다음과 같습니다.

**동작 확인한 것**

- 서버: 탐지, 판정(가림·차단·기록), 이름표 치환, 응답 검사. 자동 시험 275개 통과
- 크롬 확장: chatgpt.com에서 가림 전송, 입력 중 사전 경고, 차단 동작 확인
- 예외 요청 → 관리자 승인 → 기간 내 허용 → 사용 완료·회수. 안 쓴 1회 승인은 하루 뒤 만료
- 콘솔: 규칙 시험, 적용 중 승인 목록, 예외 표시가 붙은 기록
- 키워드 없이도 IP 주소, API 키는 차단
- 배포: Docker, Railway. main 병합 후 자동 배포 워크플로 (저장소 비밀값 설정 필요)

**발표에서 뺀 것과 그 이유**

- 답변 속 이름표를 원래 값으로 되돌려 보여 주는 복원: 서버 쪽 주소(`/v1/restore`)와 시험은 있으나 ChatGPT 화면 쪽 제약(메일 카드 영역, 30분 제한, Gmail 같은 외부 도구로의 전달)이 있어 기능으로 내세우지 않았습니다
- 사내 앱용 API의 실제 모델 연동: 모의 모델로만 시험
- 로그인·사내 계정 연동: 계획 없음. 브라우저 번호와 앱 키로 구분
